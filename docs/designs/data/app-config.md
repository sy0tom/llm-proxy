# 設定ファイル

## 目的

Gatewayの設定ファイル`config.yaml`の構成と各項目を定める。

## 構成

設定ファイルは`config.yaml`とし、以下の構成とする。

[設定ファイル](../../../config.yaml)

## 項目

| 項目         | 説明                                       |
| ------------ | ------------------------------------------ |
| `server`     | Gatewayの起動設定                          |
| `providers`  | Providerの接続先および認証設定             |
| `models`     | モデルルーティングおよび推論パラメータ設定 |
| `timeout`    | リクエスト全体の実行時間上限（秒）         |
| `parameters` | モデルエイリアス単位の推論パラメータ       |

`models`のキーの解決規則は[モデルルーティング](../../specs/FC-001.md)を参照する。

## 読み込みと反映

- 設定ファイルのパスは環境変数`CONFIG_PATH`で変更可能とする。
- 起動時に設定ファイルのバリデーションを行い、不正な場合は起動に失敗する。
- 設定の変更はGatewayの再起動によって反映する。
- Hot Reloadは初期実装の対象外とする。

## モデル設定例

| モデルエイリアス | Provider  | 実モデル                     | Context  | 最大生成トークン | Thinking |
| ---------------- | --------- | ---------------------------- | -------- | ---------------- | -------- |
| claude-\*        | Anthropic | リクエストで指定されたモデル | 変更なし | 変更なし         | 変更なし |
| local-lite       | Ollama    | Gemma                        | 16K      | 2048             | OFF      |
| local-middle     | Ollama    | Gemma                        | 32K      | 4096             | OFF      |
| local-heavy      | Ollama    | Gemma / Qwen / GPT-OSS       | 64K      | 8192             | ON       |

上記の推論パラメータは初期設定の候補とする。
実際の推論速度、メモリ使用量、回答品質をもとに調整する。

## 注意事項

上記はGateway独自の設定仕様である。
各推論パラメータをProviderのAPIで制御できることを保証するものではない。
対応可否は技術検証で確認する。
