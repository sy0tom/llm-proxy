# FC-001: モデルルーティング

## 目的

リクエストのモデルIDから、接続先のProviderと実モデルを解決する規則を定める。

## 解決の優先順位

モデルIDの解決は以下の優先順位で行う。

1. 完全一致
2. ワイルドカード一致
   - 複数の設定に一致する場合は最も長いプレフィックスを優先する。
3. 一致する設定が存在しない場合はエラーを返却する。

一致しない場合に、別のモデルやクラウドLLMへフォールバックしない。

## 設定との関係

ルーティングの対象は[設定ファイル](../designs/data/app-config.md)の`models`に定義する。
`claude-*`のようにワイルドカードを指定した設定では、実モデルを変更せず、
リクエストで指定されたモデルIDをそのまま上流へ渡す。
